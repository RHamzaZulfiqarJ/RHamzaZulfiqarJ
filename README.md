## A little context

I’m Hamza. I like taking ideas that are still half conversation, half sketch—and turning them into software people can use without a manual.

Most of my work lives somewhere between **product design, frontend craft, backend structure, and stubborn debugging**. I enjoy the whole path: shaping the data, building the awkward first version, finding the edge cases, and polishing the part users actually touch.

I’m not here to collect technologies. I use them to make things.

## My workbench

```text
browser side     Next.js · React · TypeScript · Tailwind
server side      FastAPI · Node.js · Server Actions
data side        PostgreSQL · Supabase · Prisma · SQLAlchemy
shipping side    Docker · Kubernetes · Vercel · testing
```

The list changes. The habits do not:

- understand the workflow before drawing the interface;
- make invalid states difficult to create;
- keep data access explicit;
- write down the decisions future-me will forget;
- leave the codebase easier to enter than I found it.
